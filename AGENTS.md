# Download repository instructions

This public repository distributes approved CONN-X Expenses Android installers and user-facing documentation only.

- Application development, builds, tests, signing and private evidence belong in the private CONNX-ExpensesApp project.
- Build and verify privately first. Obtain Olivier's explicit approval for each specific APK before copying it here. A previous approval, build, merge, tag or successful check does not authorize another public upload.
- The October 26, 2026 request approves existing Android Build 19 only. It does not authorize future builds or production employee rollout.
- Copy the exact approved APK without rebuilding or re-signing. Store APKs as versioned GitHub Release assets; keep binaries out of Git history.
- Include a checksum file and reviewed public build metadata. Keep source, credentials, signing keys, private logs, employee data and real receipts out of this repository.
- Verify the uploaded artifact and anonymous download against the private SHA-256 and size before changing the README to advertise it as available.
- Keep English/French installation guidance, TEST status and remaining acceptance limits accurate. Never advise uninstalling or clearing app data to update.
- Do not automatically mirror private builds. Do not send tester or employee notifications without authorization.
- GitHub publication of Build 19 is pending; the README currently uses the existing temporary Expo link. Do not claim a GitHub APK exists until the asset upload and verification succeed.
