### Install or update / Installer ou mettre à jour

1. Open the APK download link on your Android phone.
2. Download the file, then open it from Downloads.
3. Install or update only if company device policy permits installation from that source. If blocked, contact your IT administrator.
4. Install **over the existing CONN-X Expenses Offline app**. **Do not uninstall or clear app data:** this app has no backup/restore and local history can be lost.

Ouvrez le lien sur votre téléphone Android, téléchargez puis ouvrez l’APK et installez la mise à jour si la politique de l’entreprise le permet. Si l’installation est bloquée, contactez votre administrateur informatique. **Ne désinstallez pas l’application et n’effacez pas ses données : l’historique local peut être perdu.**

Updates are manual. Download and install the next approved APK over the existing app. The application does not update itself.
